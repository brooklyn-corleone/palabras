# Palabras — установка

Приложение собрано и работает локально. Осталось выложить его на GitHub Pages.

```
CLAUDE.md              инструкции для Claude Code, читаются автоматически
palabras-spec.md       исходная спека (часть решений изменилась — см. CLAUDE.md)
deck.seed.json         колода: ser, estar, tener, семья, части тела
notes.seed.json        правила и таблицы, всплывают между карточками
index.html, styles.css, sw.js, manifest.webmanifest, src/, icons/
reference/palabras.html  прототип — образец логики повторений, в сайт не входит
SETUP.md               этот файл
```

Перевод — **испанский ↔ русский**.

---

## Что нужно на компьютере

- `git`
- `gh` — GitHub CLI, [cli.github.com](https://cli.github.com)
- Claude Code
- Python 3 (для локального сервера, на macOS уже есть)

Проверить одной строкой:

```bash
git --version && gh --version && python3 --version
```

---

## Установка

**1. Положи папку куда удобно и зайди в неё**

```bash
cd ~/projects/palabras
```

**2. Авторизуй GitHub CLI** (один раз на компьютер)

```bash
gh auth login
```

Выбирай: GitHub.com → HTTPS → Login with a web browser.

**3. Запусти Claude Code**

```bash
claude
```

Он сам подхватит `CLAUDE.md` при старте.

**4. Дай команду на публикацию**

> Создай через gh публичный репозиторий palabras, закоммить всё, запушь и включи GitHub Pages из ветки main, папка root. В конце скажи мне URL сайта.

Дальше он работает сам. Проверяй команды перед подтверждением — особенно всё, что удаляет файлы или трогает другие репозитории.

**5. Проверь локально, пока он работает**

```bash
python3 -m http.server 8000
```

и открой `http://localhost:8000`. Через `file://` не заработает: ES-модули и service worker требуют настоящий http.

**6. Поставь на телефон**

Открой полученный URL в Safari или Chrome → «Поделиться» → «На экран Домой». Появится иконка, приложение откроется без адресной строки и будет работать офлайн.

**7. Настрой синхронизацию между своими устройствами**

Это единственный способ не потерять прогресс: браузеры чистят данные сайтов, которыми давно не пользовались.

1. Зайди на [github.com/settings/personal-access-tokens](https://github.com/settings/personal-access-tokens)
2. Generate new token → **Fine-grained**
3. В разделе **Account permissions** включи **Gists → Read and write**. Больше ничего не включай.
4. Срок действия — год, потом придётся обновить.
5. Скопируй токен и вставь в настройках приложения на каждом своём устройстве.

Токен вставляется **в приложение**, не в терминал. Claude Code его видеть не должен.

**8. Отправь ссылку девушке**

Ничего настраивать ей не нужно — открывает ссылку, ставит на домашний экран, учит. Колода и прогресс у неё свои. Токен нужен только если она захочет учить с двух устройств.

## Как пополнять базу

Заходишь в папку, запускаешь `claude` и говоришь обычными словами:

> добавь в deck.seed.json:
> cuchara — ложка
> tenedor — вилка
> servilleta — салфетка
> проставь id, часть речи и тему. закоммить и запушь.

После пуша слова появятся при следующем открытии приложения — у тебя и у неё, каждому
в первую коробку. Прогресс это не затронет.

Формат слова:

```json
{ "id": "familia-madre", "es": "la madre", "ru": "мать", "pos": "n", "cat": "familia" }
```

`pos` — часть речи (`n`, `v`, `adj`, `phrase`), она нужна режиму с вариантами ответа:
дистракторы подбираются в первую очередь из той же части речи.

`cat` — тема. Названия тем лежат отдельным словарём в начале файла:

```json
"categories": { "verbos": "Глаголы", "familia": "Семья", "cuerpo": "Тело" }
```

Новую тему заводишь так же — дописал строку в словарь, проставил `cat` у слов, запушил.
В приложении она сразу появится в настройке занятия и в фильтре списка слов.

**Единственное правило: `id` слова никогда не меняется.** Переименовал `id` — приложение
считает это новым словом, а прогресс по старому теряется.

Остальные поля (`es`, `ru`, `pos`, `cat`) правь свободно: слово, которое ты не редактировал
в самом приложении, подтянет новую версию из репозитория при следующем открытии.
Как только слово поправлено с телефона, оно замораживается и пополнение его больше не трогает.

## Как добавлять правила и таблицы

Это второй канал — `notes.seed.json`. Такие карточки не спрашивают и не оценивают,
они просто всплывают между обычными примерно раз в восемь ответов.

> добавь в notes.seed.json таблицу спряжения глагола ir в настоящем времени

Таблица:

```json
{
  "id": "ir-presente",
  "title": "Verbo IR — настоящее время",
  "kind": "table",
  "head": ["", "ir"],
  "rows": [["Yo", "voy"], ["Tú", "vas"]],
  "note": "Короткое пояснение под таблицей — необязательно."
}
```

Простая заметка без таблицы:

```json
{ "id": "por-para", "title": "por или para", "kind": "text", "body": "Текст правила." }
```

Что ещё удобно просить:

> собери 40 слов по теме «врач и аптека», уровень A2, добавь в колоду
> найди в колоде дубли и слова без части речи
> добавь таблицу неправильных глаголов в pretérito

Слова, добавленные прямо в приложении с телефона, живут только у тебя и в репозиторий
не попадают. Это отдельный канал.


## Как собрать занятие под себя

На вкладке «Учить» — строка с текущими настройками и кнопка «Настроить занятие»:

- **Какие слова** — что созрело к повторению, случайные из колоды, или отмеченные галочками
  на вкладке «Слова».
- **Тема** — все или несколько сразу (Глаголы, Семья, Тело, Дом, Спальня).
- **Сколько слов** — все, 10, 20, 30. Считается в словах, а не в карточках.
- **Формат** — авто (движок сам выбирает по коробке) или несколько конкретных сразу:
  квиз, ввод, из букв, карточки, пары. Выбрал квиз и карточки — занятие будет из них двоих.

Настройки живут до перезагрузки: открыл приложение заново — обычное повторение.

Дневная цель (по умолчанию 20) теперь останавливает занятие: на двадцатом ответе появляется
экран с выбором «продолжить или хватит», а не счётчик, который молча уезжает в 21, 22, 23.

## Как вносить правки

Так же — через `claude` в этой папке:

> сделай интервалы коробок 1/3/7/14/30 вместо текущих
> добавь в режим с вариантами четвёртый вариант ответа
> шрифт слова на карточке слишком крупный на телефоне, уменьши

После правок он коммитит и пушит, GitHub Pages обновляется за минуту.

## Если что-то не работает

**Сайт не открывается после включения Pages.** Первая сборка занимает до пары минут. Проверь Settings → Pages: ветка `main`, папка `/ (root)`.

**Запушил, а на телефоне старая версия.** Service worker отдаёт закэшированную оболочку, обновление подхватывается со второго открытия. Это нормальное поведение PWA. Чтобы форсировать — закрыть приложение полностью и открыть заново.

**Новые слова или правила не появились.** Проверь, что `deck.seed.json` и `notes.seed.json` действительно в репозитории на GitHub, а не только локально. И что у слов уникальные `id`.

**Пустой экран, в консоли ошибки про модули.** Открыл через `file://`. Нужен `python3 -m http.server`.

**Прогресс пропал.** Если синк не был настроен — восстановить нечего. Настрой его сразу, а не когда-нибудь.
